# 🎮 **Mona Mayhem**
## *Battle Your GitHub Legacy*

Ever wondered how your contributions stack up against a rival? **Mona Mayhem** is a retro arcade-themed showdown where two GitHub users enter, and only one's contribution graph leaves victorious.

![Mona Mayhem Screenshot](https://github.com/user-attachments/assets/5eca79e2-cb9f-4e93-aa0d-23666ebde3b7)

---

### 🕹️ **What You'll Build**

A blazingly fast web arena that:
- 🔥 **Fetches real GitHub data** — Your actual contributions, streaks, and all
- 📊 **Visualizes the battle** — Side-by-side arcade-style comparison
- ⚡ **Runs instantly** — Built with Astro for lightning-fast performance
- 🎯 **Crushes nostalgia** — Retro 8-bit gaming vibes meet modern web tech

And here's the twist: **You'll build this with AI.** Using GitHub Copilot, you'll learn the entire stack in an interactive workshop.

---

## 🚀 **Get Started in 3 Steps**

### 1️⃣ **Set Up Your Arena**
```bash
# Clone or fork this repo
git clone <your-repo-url>
cd mona-mayhem

# Install dependencies
npm install
```

### 2️⃣ **Choose Your Path**
Pick how you want to build:
- 💻 **VS Code Track** — Interactive chat, planning mode, and visual agent work
- 🖥️ **CLI Track** — Terminal-powered with GitHub Copilot CLI for full control

### 3️⃣ **Follow the Workshop**
Head to [Workshop Guide](workshop/00-overview.md) and let Copilot guide you through building the entire app.

## ✅ **Prerequisites**

### Required
- ✨ **GitHub Copilot** (Pro, Business, or Enterprise subscription)
- 🔧 **Git** (version control)
- 📦 **Node.js** (v18+)

### For VS Code Track
- 💻 VS Code v1.107+
- 🤖 GitHub Copilot extension (signed in)

### For CLI Track
- 🖥️ GitHub Copilot CLI (`copilot`)
- 📦 Node.js 22+ (for npm installation)
- *Or install via Homebrew/WinGet*
